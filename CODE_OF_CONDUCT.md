# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the code and the documents it validates. Harassment, personal attacks and posting anyone's real ID numbers or personal data are not allowed.

Report unacceptable behavior to alejandro@valtechstudio.com. Reports are handled confidentially by Val Tech Studio, who may remove comments, issues or contributors that break these rules.
